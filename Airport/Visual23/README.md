# Airport visual23

Run **Run Visual23.cmd** for the revised playable airport. Unreal Engine is required. WASD/mouse move and look, E/click operates the aimed control, B shows the journey boarding pass, Space stands from a seat. The existing passenger process, aircraft and characters are retained.

The visual revision has its own native map `/Game/Airport23/L_Airport_Visual23`, meshes and material instances. It does not overwrite the Compact12 Blender source or Journey22 map. `Airport_Visual23.blend` is the editable modeled kit, not a flattened full terminal scene. The earlier full scene remains in `../Compact12/Airport.blend`.

`Review.html` contains seven matched native before/after camera pairs and the room-based spatial plan. PNG pixels are unaltered. Sharpening is zero; antialiasing stays on, without a blur filter. Radii/normals were revised on 38 asset families. Three full-size mezzanine pieces avoid stretched per-instance bevels. Satin material instances tame metallic glare and microscopic surface detail, with narrower tile joints. Native daylight uses the verified character-map balance; grain, motion blur and gameplay depth of field are disabled.

The floor plan is **planned, not built**. `Planning/Zoning23.json` now defines seventeen non-overlapping zones and nineteen thresholds in plan revision24. It connects public check-in to a landside corridor; security exits through a recovery vestibule into a 6 m wide airside concourse. Individual A07/A08 lounges, café and amenities branch off through recessed approaches and offset openings. Most internal thresholds remain open, with doors only where they serve a purpose. Arrivals has its own public return passage. The next construction stage needs actual walls, entry portals, room ceilings, furniture relocation and navigation verification. The visual revision keeps the old tested circulation so this design change is not silently presented as finished.

Rebuild with Blender using `SourceAssets/model_visual23.py`, then native Unreal Python commandlet `SourceAssets/build_visual23_unreal.py`. Capture fixed views with `SourceAssets/run_photos23.py Before` or `After`; Before uses preserved Journey22. Generate the plan with `SourceAssets/make_plan24.py`; build the review and verify image/source hashes with `SourceAssets/make_review23.py`. RecoveryBefore23 stores the edited runtime files' prior contents. Rejected dark-lighting photos are retained under ArtBible/Diagnostics.

This pass does not finish character art, author later story events or connect parked-aircraft boarding to the separate flight mode. The style README remains `../ArtBible/Original_Readme.md`; relevant rules are visible rigid-edge bevels, clean normal handling, restrained normal textures, material-specific roughness, moderate sharpening without crunchy outlines and readable physical spaces.
